# Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is a React-based online plant shopping application.

The application allows users to:

- Browse plants by category
- View plant images, names, descriptions, and prices
- Add plants to a shopping cart
- Increase and decrease product quantities
- Remove products from the cart
- View the total number of items
- View the total cart amount

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- React Redux
- React Router
- CSS
- Vite

## Plant Categories

The application contains three plant categories:

1. Indoor Plants
2. Outdoor Plants
3. Succulents

Each category contains at least six plants.
